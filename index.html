Open Susty Scans

A free, open-source tool that checks websites for sustainability signals using Lighthouse, CO2.js, and WSG-aligned analysis. Submit up to 500 URLs via a GitHub issue and get detailed reports.

Enter the site URL (e.g. https://example.gov) or a short name. This becomes the GitHub issue title: SCAN: [your entry]. If you enter a site URL here, pages will be discovered automatically; otherwise, add URLs in the field below.

Paste one URL per line (or comma-separated). HTTP and HTTPS only. Up to 500 URLs. Not sure which pages to include? Use Top Task Finder to identify a good set of pages.
